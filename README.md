# biblija-azuriranja

Ovde je samo `version.json`: broj najnovije verzije aplikacije Biblija i spisak novina.
Aplikacija na telefonu ga proverava da bi znala da li postoji nova verzija.

U folderu `paket/` je šifrovan paket najnovije verzije; aplikacija ga sama preuzme i otključa
ključem koji ima samo ona. Čitljivog teksta Biblije ovde nema — izvor je u privatnom repozitorijumu.
